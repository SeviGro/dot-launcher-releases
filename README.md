# Dot-Launcher

Ein Android-Startbildschirm ohne Icon-Raster: ein Punkt am unteren Rand –
gedrückt halten, und sechs Apps erscheinen im Kreis. Weiter halten und
hochziehen blättert durch bis zu acht Ebenen. Alles mit dem Daumen erreichbar.

Hier liegen nur die fertigen Versionen zum Herunterladen, kein Quellcode.

## Herunterladen

Unter **[Releases](../../releases/latest)** die Datei `Dot-Launcher-x.y.apk`
laden und auf dem Handy antippen.

- Android 8.0 oder neuer
- Neue Versionen **über die alte installieren** – nicht vorher deinstallieren,
  sonst sind die Einstellungen weg.
- Ab Version 1.7 meldet sich der Launcher selbst, wenn es hier eine neue
  Version gibt (einmal am Tag, abschaltbar).

## Echtheit prüfen

Jede Version ist mit demselben Schlüssel signiert (`CN=Severin Großauer`).
Android installiert ein Update nur, wenn der Schlüssel übereinstimmt. Die
SHA-256-Prüfsumme steht beim jeweiligen Release.
